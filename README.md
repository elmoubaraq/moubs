# Evergreen - PDF Scanner & Converter Super App

Evergreen is an all-in-one document management utility designed to make your daily document workflows seamless, free, and efficient. With a sleek, eco-friendly green-themed user experience, Evergreen brings power and simplicity directly to your device. 

## Features
- **Document Scanner**: Scan your physical documents with auto-cropping and perspective correction.
- **Image to PDF**: Select multiple images and easily convert them into a single PDF document.
- **Merge PDF**: Combine multiple PDF files securely right on your device.
- **Compress PDF**: Reduce file sizes smoothly before sharing or storing.
- **Sign Document**: Digitally sign your PDF files directly without needing external tools.
- **ID Photo**: Crop images tailored to passport and standard ID photo dimensions.
- **OCR Text Extraction**: Extract text instantly from scanned files and images.
- **Organize Pages**: Reorder, rotate and remove pages with live thumbnails.
- **Split, Watermark, Encrypt & Unlock**: Extract page ranges, stamp text, and add or remove password protection.
- **PDF Viewer**: Search text inside documents, print, and share.
- **My Files**: Search, filter, star, rename and batch-delete your documents.

## Technology Stack
- **Framework**: Flutter
- **State Management**: Riverpod
- **Local Storage**: Hive
- **Monetization**: Google Mobile Ads (Banner, Native, and Interstitial)
- **Routing**: GoRouter

## Getting Started

To run this application locally:
1. Ensure you have the Flutter SDK installed (Dart `>=3.11.1`; tested on Flutter 3.41). Android builds need minSdk 24.
2. Run `flutter pub get` to install dependencies.
3. Run `flutter run` on a connected device or emulator.
4. Run `flutter test` for the unit tests.

**Note:** Evergreen operates entirely strictly as an ad-supported, premium-free application.
